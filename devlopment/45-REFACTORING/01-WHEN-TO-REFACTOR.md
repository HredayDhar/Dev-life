# 01 — When to Refactor

## 1. What Is This?

Knowing when to refactor involves recognizing the signs, signals, and circumstances that indicate code would benefit from restructuring without changing behavior. It encompasses understanding the trade-offs between immediate feature work and long-term health, detecting code smells, assessing technical debt impact, and timing refactoring efforts to maximize value while minimizing risk.
